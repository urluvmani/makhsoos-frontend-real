I designed and developed a full-stack e-commerce web application using React.js, Node.js, Express.js, and MongoDB, tailored for launching a personal online business.
The platform includes product management, cart system, admin dashboard, and intelligent search functionality, ensuring a smooth and responsive user experience.
To maintain focus on sales, authentication was limited to admin users, minimizing user distractions while maximizing performance efficiency.
The project achieved an exceptional Lighthouse score — 100% performance, 100% best practices, 77% accessibility, and 92% SEO compliance.
The application was entirely self-built, integrating GPT-powered automation for optimized code generation and rapid prototyping, ensuring industrial-grade quality and modern scalability.
